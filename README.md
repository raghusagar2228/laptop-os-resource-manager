# Laptop OS Resource Manager

A C-based simulation of a laptop operating system that demonstrates basic operating system resource and power management concepts.

## Features

- Process Management
- FCFS CPU Scheduling
- Memory Management
- Storage Management
- Device Management
- Power Management
- System Status
- Menu-driven interface

## Technologies Used

- C Programming Language
- GCC Compiler
- Geany IDE

## Project Objective

The objective of this project is to demonstrate important operating system concepts through a simple software simulation. It is designed for educational purposes and does not represent a complete operating system.

## How to Run

Compile the program using GCC:

```bash
gcc laptop_os.c -o laptop_os
